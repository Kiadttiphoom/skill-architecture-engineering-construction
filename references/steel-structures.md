# โครงสร้างเหล็กและโลหะ (Steel Structures)

## 1. มาตรฐานการออกแบบโครงสร้างเหล็กไทย พ.ศ. ๒๕๖๗ [S-015]
  - รองรับ ๒ วิธีการคำนวณมาตรฐานสากล:
    (๑) **วิธีตัวคูณความต้านทานและน้ำหนักบรรทุก (LRFD):** โหลดแฟกเตอร์ $1.2D + 1.6L + 0.5(W 	ext{ or } E)$
    (๒) **วิธีหน่วยแรงที่ยอมให้ (ASD):** โหลดแฟกเตอร์ $D + L$ หรือ $D + 0.75L + 0.75(W 	ext{ or } E)$
  - **คุณสมบัติวัสดุเหล็กรูปพรรณ (ตาม มอก. 1227 / 107):**
    - ชั้นคุณภาพ SS400 / SM400: กำลังคราก ($F_y$) ขั้นต่ำ $2,400\ kg/cm^2$ (235–245 MPa), กำลังดึงประลัย ($F_u$) $4,000–5,100\ kg/cm^2$
    - ชั้นคุณภาพ SS490 / SM490: กำลังคราก ($F_y$) ขั้นต่ำ $3,200\ kg/cm^2$ (315–325 MPa)
    - โมดูลัสยืดหยุ่นของเหล็ก ($E$): $2.04 	imes 10^6\ kg/cm^2$ (200,000 MPa)

---

## 2. การป้องกันไฟและการทนไฟของโครงสร้างเหล็ก [S-016]
  - เหล็กรูปพรรณสูญเสียกำลังรับน้ำหนักลงกว่าร้อยละ ๕๐ เมื่ออุณหภูมิสูงเกิน ๕๐๐ องศาเซลเซียส
  - เสาและคานเหล็กในอาคารสูง อาคารขนาดใหญ่พิเศษ หรืออาคารสาธารณะ ต้องหุ้มด้วยวัสดุทนไฟ (Fireproofing) เช่น:
    - คอนกรีตหุ้มหนาไม่น้อยกว่า ๕.๐ ซม. (ทนไฟ ๓ ชั่วโมง)
    - แผ่นยิปซัมกันไฟหลายชั้น
    - การพ่นสีพองตัวกันไฟ (Intumescent Paint) ให้ได้อัตราการทนไฟ ๑–๓ ชั่วโมงตามที่กฎหมายกำหนด

---

## 3. การป้องกันสนิมและโครงสร้างสัมผัสน้ำ (นวัตกรรมบ้านลอยน้ำ DPT Plan 361) [S-020]
  - โครงสร้างเหล็กที่อยู่ในพื้นที่ชื้นแฉะหรือสัมผัสน้ำ ต้องชุบสังกะสีแบบจุ่มร้อน (Hot-Dip Galvanized) ความหนาชั้นเคลือบไม่น้อยกว่า ๕๐๐–๖๐๐ $g/m^2$ (หนาประมาณ ๗๐–๘๕ ไมครอน) หรือใช้สีอีพ็อกซี่เกรดทางทะเล (Marine Epoxy Coating)
